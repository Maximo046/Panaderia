ARCHIVO: sidebar.php
TITULO PARA EXPONER: Menu de navegacion responsive y filtrado por rol.
PROPOSITO: generar una unica navegacion compartida, mostrar solo las secciones que corresponden al rol y marcar la pagina actual.
TIPO: plantilla PHP/HTML parcial; no es una pagina independiente ni una clase orientada a objetos.

CONTEXTO Y CONTRATO
Las paginas autenticadas definen $pagina_actual, inician la sesion y hacen include de este archivo. La sesion contiene el rol guardado durante el login. Este archivo produce HTML en el flujo de salida de la pagina que lo incluye; no ejecuta una peticion ni consulta la base de datos.

EXPLICACION DE CADA VARIABLE Y DE SU CREACION
1. $_SESSION: superglobal de PHP; no se declara con $variable = ... en este archivo. PHP la proporciona despues de session_start(). Mantiene datos entre peticiones del mismo navegador.
2. $rol_del_usuario = $_SESSION['usuario_rol'] ?? '':
   - $rol_del_usuario es una variable local de tipo string en la ejecucion normal.
   - La clave asociativa 'usuario_rol' se escribe en la sesion cuando index.php valida el login.
   - ?? (coalescencia nula) selecciona '' cuando la clave no esta definida o es null; evita un aviso de indice inexistente.
3. $items_del_menu = [...]:
   - Es un array asociativo PHP, creado como literal con corchetes. Cada clave ('stock', 'insumos', etc.) identifica el modulo y cada valor es un array asociativo interno.
   - 'etiqueta' contiene el texto visible; 'enlace' contiene la ruta relativa; 'roles' contiene una lista (array indexado) de strings de rol autorizados a ver el enlace.
   - Se define una sola vez por ejecucion de la pagina. No es un objeto ni una tabla de la base de datos.
4. $clave y $item, variables de iteracion creadas por foreach:
   - foreach ($items_del_menu as $clave => $item) recorre el array.
   - $clave es string, por ejemplo 'stock'; $item es un array asociativo con etiqueta, enlace y roles.
   - La expresion => enlaza cada clave con el valor que le corresponde durante esa vuelta.
5. continue:
   - Si in_array($rol_del_usuario, $item['roles'], true) es falso, continue salta el resto de esta iteracion y empieza la siguiente.
   - in_array busca un valor en un array; el tercer argumento true exige que coincidan tipo y valor, no solo el valor tras conversion implicita.
6. $activo = ($pagina_actual === $clave):
   - Variable booleana calculada para el elemento actual.
   - $pagina_actual debe existir en la pagina incluyente. === compara valor y tipo estrictamente. El menu no asigna esta variable ni determina permisos de backend.
7. El operador ternario ($activo ? ' active' : '') selecciona una porcion de texto. El mismo patron imprime aria-current="page" solo cuando el enlace corresponde a la vista actual.

DETALLE DEL ARRAY
Las claves son identificadores internos estables que se comparan con $pagina_actual. 'etiqueta' y 'enlace' son strings. 'roles' es una lista de strings. Por ejemplo, la entrada reportes restringe visualmente el enlace a Administrador; stock, insumos, produccion, productos, salidas y ayuda incluyen ambos roles. La entrada registro tambien es exclusiva del administrador.

GENERACION HTML Y ESCAPE
- <?php ... ?> abre/cierra bloques PHP.
- ?> permite que el resto se interprete como HTML fijo.
- <?= expresion ?> equivale a imprimir el resultado de la expresion.
- <nav> delimita navegacion; <aside> es contenido lateral; <a href> crea enlaces; <button> es un control interactivo; <span> contiene el icono visual.
- htmlspecialchars($item['enlace'], ENT_QUOTES, 'UTF-8') convierte caracteres especiales a entidades HTML para que los datos impresos no se interpreten como marcado. ENT_QUOTES incluye comillas simples y dobles; UTF-8 declara la codificacion.
- class="..." se construye combinando una clase fija nav-link con el sufijo condicional active. Las llaves PHP dentro del atributo permiten interpolar el resultado.

BOOTSTRAP 5.3 Y RESPONSIVE
- navbar, container-fluid, navbar-toggler y navbar-brand estructuran la barra superior.
- d-lg-none es una utilidad responsive que oculta la barra en el breakpoint lg y superiores.
- offcanvas-lg, offcanvas-start, offcanvas-header, offcanvas-body y btn-close configuran el panel lateral que se vuelve desplegable en pantallas pequenas y parte del layout en pantallas grandes.
- nav y flex-column presentan los enlaces en columna.
- data-bs-toggle="offcanvas" le indica al JavaScript de Bootstrap que el boton abre/cierra un offcanvas; data-bs-target="#menuLateral" identifica el elemento por su id.
- aria-controls, aria-label, aria-current y tabindex son atributos de accesibilidad y navegacion con teclado, no clases ni variables PHP.
- Bootstrap no calcula el rol. PHP decide que enlaces emitir; JavaScript de Bootstrap solo controla la apertura/cierre del panel.

FLUJO DE EJECUCION PARA LA DEFENSA
1. Una pagina protegida inicia la sesion y define su identificador.
2. sidebar.php toma el rol de $_SESSION.
3. Define la configuracion declarativa de enlaces una vez.
4. Itera cada modulo; si el rol no esta permitido, no produce ese enlace.
5. Calcula si el enlace es la pagina actual y agrega el estado visual.
6. PHP entrega el HTML resultante al navegador.
7. En movil, el usuario acciona el boton y Bootstrap muestra el offcanvas.

DECISION DE DISENO Y LIMITE DE SEGURIDAD
El array central evita repetir el menu en cada pagina y permite relacionar rol, etiqueta y ruta en un solo lugar. La visibilidad del enlace es solo presentacion: una persona puede escribir una URL directamente. auth.php aplica la autorizacion de paginas; cada endpoint que cambia datos debe comprobar su propio rol. En una defensa conviene explicar esta diferencia entre ocultar una opcion y autorizar realmente una operacion.
