INVENTARIO DE VARIABLES, PARAMETROS Y OBJETOS

ALCANCE Y COMO LEERLO
Este inventario corresponde al codigo de aplicacion propio activo y revisado. No lista variables internas de Bootstrap, DataTables, PHPMailer o Dompdf: esas dependencias tienen guias separadas. Tampoco lista las miles de variables internas de PHP/MySQL.

PHP es de tipado dinamico: el tipo indicado es el tipo normal observado/inferido por su asignacion y uso, no una declaracion obligatoria del lenguaje. Algunos resultados SQL pueden ser false si la consulta falla. Las variables de foreach/while nacen al ejecutar el bucle y cambian con cada vuelta. $_POST, $_GET, $_SESSION y $_SERVER son superglobales administradas por PHP, no se crean manualmente. Un array no es lo mismo que un objeto.

OBJETOS PROPIOS/EXTERNOS QUE APARECEN
- $conexion: instancia de mysqli creada con new mysqli en conexion.php. La comparten los archivos incluidos y los endpoints que requieren ese archivo.
- $consulta_insumo, $insertar_compra, $actualizar_stock, $verificar_producto, $verificar_insumo, $stmt, $consulta_producto, $consulta_stock, $insertar_salida, $descontar_stock: instancias mysqli_stmt creadas por prepare() para consultas parametrizadas.
- $correo: instancia PHPMailer creada con new PHPMailer(true); aparece en correo de alerta y contacto.
- $dompdf: instancia Dompdf creada para producir PDF.
- No se definen clases propias de dominio en el codigo activo. Se definen funciones PHP y se instancian clases de bibliotecas/extensiones.

SUPERGLOBALES Y DATOS DE SOLICITUD
$_POST: array asociativo de campos de formulario enviados por POST.
$_GET: array asociativo de parametros en URL, como mes.
$_SESSION: array asociativo persistente entre solicitudes del mismo usuario; PHP lo conecta a una cookie de sesion.
$_SERVER: array de informacion de solicitud/servidor; aqui se lee REQUEST_METHOD.
php://input: cuerpo crudo de solicitud leido como string en registrar_compra.php; no es una variable PHP.

VARIABLES SQL Y DE PLANTILLA
SQL no usa variables de aplicacion declaradas con $nombre. Los signos ? de prepared statements son marcadores que mysqli_stmt recibe por bind_param. Los alias SQL con AS, por ejemplo cantidad AS stock_actual, son nombres temporales de columnas en el resultado, no variables PHP hasta que fetch_assoc crea el array de fila.
Los nombres name="id_producto[]" del HTML no son variables JavaScript/PHP en el navegador; son claves de controles que el navegador serializa y PHP materializa en $_POST cuando llega la solicitud.
