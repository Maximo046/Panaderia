ARCHIVO: README.md
PROPOSITO: guia de presentacion, requisitos e instalacion del proyecto.
TIPO: documento Markdown, no codigo ejecutado por PHP.

CONTENIDOS
Describe el proposito funcional del sistema, tecnologias (PHP, MariaDB, Bootstrap, DataTables, PHPMailer y Dompdf), requisitos locales y pasos de instalacion en XAMPP.
Los bloques marcados con triple tilde inversa son bloques de codigo para que Markdown conserve formato; los bloques de terminal muestran comandos del usuario, no comandos ejecutados automaticamente por la aplicacion.
Las rutas C:\xampp\htdocs, URLs localhost y parametros de ejemplo explican donde ubicar/importar el proyecto. El archivo SQL recomendado es database/panaderia.sql. El usuario de prueba indicado en el README pertenece a datos de desarrollo y no debe reutilizarse en despliegues reales.

FORMATO MARKDOWN
# crea encabezado; - crea lista; | separa celdas de tabla; **texto** aplica negrita; > crea una cita o nota; ![Login](ruta) inserta una captura; <http://...> forma un enlace.

RELACION
El README orienta la instalacion; las guias dentro de explicacion/ amplian el significado tecnico archivo por archivo. Para cambios en dependencias o configuracion se debe actualizar el README correspondiente.
